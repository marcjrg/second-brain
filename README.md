# Second Brain

A modular, publicly shareable assistant framework with private per-user workspaces.

## Install with ChatGPT

Copy and paste this one sentence into a new ChatGPT conversation:

> Install Second Brain for me using https://github.com/marcjrg/second-brain/blob/main/INSTALL.md

The assistant should follow [INSTALL.md](INSTALL.md), verify what it can do, guide creation of a **private** workspace, and introduce the framework. Capabilities depend on the user's tools and platform.

## Everyday use
- **Modes → Save → Actions** is the standard compact interaction menu when supported.
- Send **`!`** alone to audit and attempt recovery of Second Brain instructions and state.
- Send **`?`** alone for general help, explanations, options, next steps or status.

See [SECOND_BRAIN.md](SECOND_BRAIN.md) for the operating contract.
